Appendix: Sequences and Infinite Series¶

Download the PDF version

Guiding question

Chapter 10 leans on a few facts that its sections state and use but that need more care than a lecture allows: a bounded nondecreasing sequence converges, limits obey the usual laws, and a sequence squeezed between two sequences with the same limit has that limit. This appendix proves them. Section A starts from one assumption about the real numbers (completeness) and proves the Monotone Convergence Theorem from it. Section B uses the \(\varepsilon\)–\(N\) definition of a limit to prove the limit facts for sequences. Nothing here is needed to use the facts, only to see why they are true.

Appendix A. Completeness and the Monotone Convergence Theorem¶

Definition A.1: Upper bound, supremum

Let \(S\) be a nonempty set of real numbers. A number \(M\) is an upper bound of \(S\) if \(s\le M\) for every \(s\) in \(S\); the set \(S\) is bounded above if it has an upper bound. A number \(M^*\) is the least upper bound (or supremum) of \(S\), written \(M^*=\sup S\), if

(i) \(M^*\) is an upper bound of \(S\), and

(ii) \(M^*\le M\) for every upper bound \(M\) of \(S\).

Lower bounds, bounded below and the greatest lower bound \(\inf S\) are defined in the same way with the inequalities reversed.

The supremum need not belong to the set. The set \(\{x : 0<x<1\}\) has supremum \(1\), which is not in the set, while the set \(\{x : 0<x\le 1\}\) has supremum \(1\), which is.

The Completeness Axiom

Every nonempty set of real numbers that is bounded above has a least upper bound.

This is an assumption about the real numbers, not a theorem: it cannot be derived from the rules of arithmetic and order, so we take it as the starting point. It is exactly what the rational numbers lack. The set of rational numbers \(q\) with \(q^2<2\) is bounded above by \(2\), but among the rational numbers it has no least upper bound. Every proof in this appendix, and the Monotone Convergence Theorem on which Chapter 10 relies, rests on it.

Definition A.2: Limit of a sequence

A sequence \(\{a_n\}\) converges to the number \(L\), written \(\lim_{n\to\infty}a_n=L\), if for every \(\varepsilon>0\) there is an integer \(N\) such that

\[\abs{a_n-L}<\varepsilon \quad\text{for every } n>N.\]

A sequence that does not converge diverges. We write \(a_n\to\infty\) if for every real number \(K\) there is an integer \(N\) such that \(a_n>K\) for every \(n>N\) (and \(a_n\to-\infty\) if \(a_n<K\) for every \(n>N\) in the same way); such a sequence diverges.

Theorem A.3: Approximation property of the supremum

Let \(S\) be nonempty and bounded above, and let \(M=\sup S\). For every \(\varepsilon>0\) there is an element \(s\) of \(S\) with \(M-\varepsilon<s\le M\).

Proof. Because \(M-\varepsilon<M\) and \(M\) is the least upper bound, the number \(M-\varepsilon\) is not an upper bound of \(S\). So some element \(s\) of \(S\) satisfies \(s>M-\varepsilon\). Also \(s\le M\), because \(M\) is an upper bound of \(S\). ◻ ∎

Theorem A.4: Archimedean property

For every real number \(x\) there is a positive integer \(n\) with \(n>x\). Consequently, for every \(\varepsilon>0\) there is a positive integer \(N\) with \(\dfrac1N<\varepsilon\).

Proof. Suppose, to the contrary, that some real number \(x\) satisfies \(n\le x\) for every positive integer \(n\). Then the set \(\N=\{1,2,3,\dots\}\) is nonempty and bounded above (by \(x\)), so by the Completeness Axiom it has a supremum \(M\). By Theorem A.3 with \(\varepsilon=1\) there is a positive integer \(n\) with \(n>M-1\). Then \(n+1\) is a positive integer and \(n+1>M\), which contradicts the fact that \(M\) is an upper bound of \(\N\). This proves the first statement.

For the second, apply the first statement to \(x=1/\varepsilon\): there is a positive integer \(N>1/\varepsilon\), and then \(1/N<\varepsilon\). ◻ ∎

Theorem A.5: Monotone Convergence Theorem

(a) If \(\{a_n\}\) is nondecreasing and bounded above, then \(\{a_n\}\) converges, and its limit is \(\sup\{a_n\}\).

(b) If \(\{a_n\}\) is nonincreasing and bounded below, then \(\{a_n\}\) converges, and its limit is \(\inf\{a_n\}\).

In particular, a bounded monotonic sequence converges.

Proof. (a) The set \(S=\{a_1,a_2,a_3,\dots\}\) is nonempty and bounded above, so \(L=\sup S\) exists by the Completeness Axiom. Let \(\varepsilon>0\). By Theorem A.3 there is an index \(N\) with \(L-\varepsilon<a_N\le L\). For every \(n>N\) we have \(a_n\ge a_N\) because the sequence is nondecreasing, and \(a_n\le L\) because \(L\) is an upper bound. Hence

\[L-\varepsilon<a_N\le a_n\le L, \qquad\text{so}\qquad \abs{a_n-L}<\varepsilon .\]

Since \(\varepsilon\) was arbitrary, \(a_n\to L\).

(b) The sequence \(b_n=-a_n\) is nondecreasing, and it is bounded above by \(-m\) if \(m\) is a lower bound of \(\{a_n\}\). By part (a), \(b_n\to L'\) with \(L'=\sup\{b_n\}\). Because \(\abs{a_n-(-L')}=\abs{b_n-L'}\), we get \(a_n\to-L'\). Finally \(-L'=\inf\{a_n\}\): every \(b_n\le L'\) gives \(a_n\ge-L'\), so \(-L'\) is a lower bound; and if \(m'\) is any lower bound of \(\{a_n\}\), then \(-m'\) is an upper bound of \(\{b_n\}\), so \(L'\le -m'\), that is \(m'\le -L'\). ◻ ∎

Theorem A.6: The limit of a monotone sequence respects bounds

If \(\{a_n\}\) is nondecreasing and \(a_n\le M\) for every \(n\), then \(\lim_{n\to\infty}a_n\le M\) (and \(\lim a_n\ge a_1\)). If \(\{a_n\}\) is nonincreasing and \(a_n\ge m\) for every \(n\), then \(\lim_{n\to\infty}a_n\ge m\).

Proof. In the nondecreasing case the limit is \(L=\sup\{a_n\}\) by Theorem A.5. Since \(M\) is an upper bound of \(\{a_n\}\) and \(L\) is the least upper bound, \(L\le M\); and \(L\ge a_1\) because \(L\) is an upper bound. The nonincreasing case is the same argument applied to \(-a_n\). ◻ ∎

Example A.7: A supremum that is not a maximum

Let \(S=\{1-\tfrac1n : n=1,2,3,\dots\}=\{0,\tfrac12,\tfrac23,\tfrac34,\dots\}\). Show that \(\sup S=1\) and that \(S\) has no largest element.

Solution. Step 1: \(1\) is an upper bound. Every element is \(1-\frac1n\) with \(\frac1n>0\), so every element is less than \(1\).

Step 2: nothing smaller is an upper bound. Let \(M<1\). We must find an element of \(S\) bigger than \(M\). The number \(1-M\) is positive, so by the Archimedean property (Theorem A.4) there is an integer \(N\) with \(\frac1N<1-M\). Rearranging, \(1-\frac1N>M\), so \(M\) is not an upper bound. Hence every upper bound is at least \(1\), and \(\sup S=1\).

Step 3: no maximum. A maximum would be an element equal to \(\sup S=1\), but every element is strictly less than \(1\).

As a check on the answer, the elements get closer and closer to \(1\): \(\lim_{n\to\infty}\left(1-\tfrac1n\right)=1\), so \(\sup S=1\).

Example A.8: Monotone Convergence in action: repeated square roots

Let \(a_1=\sqrt2\) and \(a_{n+1}=\sqrt{2+a_n}\). Show that \(\{a_n\}\) converges and find its limit.

Plan. The theorem needs two facts: the sequence is monotonic and it is bounded. Terms: \(a_1\approx1.414\), \(a_2\approx1.848\), \(a_3\approx1.962\). They increase; they seem to stay below \(2\).

Bounded above by \(2\) (induction). \(a_1=\sqrt2<2\). If \(a_n<2\), then \(a_{n+1}=\sqrt{2+a_n}<\sqrt{2+2}=2\), because the square root is increasing. So \(a_n<2\) for all \(n\).

Increasing (induction). \(a_2>a_1\) since \(\sqrt{2+\sqrt2}>\sqrt2\). If \(a_n>a_{n-1}\), then \(2+a_n>2+a_{n-1}\), and taking square roots, \(a_{n+1}>a_n\). So the sequence is increasing.

Conclusion. By the Monotone Convergence Theorem (Theorem A.5) the sequence converges, say to \(L\). Taking the limit in the recurrence (the limit of \(a_{n+1}\) is also \(L\), and the square root is continuous) gives \(L=\sqrt{2+L}\), so \(L^2-L-2=0\), that is \((L-2)(L+1)=0\). Because \(a_n>0\) for all \(n\), the limit is not \(-1\). Therefore \(L=2\), and by Theorem A.6 this agrees with \(L\le 2\).

Example A.9: A nonincreasing sequence bounded below

Let \(a_1=2\) and \(a_{n+1}=\dfrac12\left(a_n+\dfrac2{a_n}\right)\). Show that \(\{a_n\}\) converges and find its limit.

Terms. \(a_2=\frac12\left(2+1\right)=\frac32\) and \(a_3=\frac12\left(\frac32+\frac43\right)=\frac{17}{12}\).

Bounded below by \(\sqrt2\). For \(a_n>0\),

\[a_{n+1}^2-2=\frac14\left(a_n+\frac2{a_n}\right)^2-2=\frac14\left(a_n-\frac2{a_n}\right)^2\ge0 ,\]

because \(\left(u+v\right)^2-4uv=(u-v)^2\) with \(u=a_n\), \(v=2/a_n\) and \(uv=2\). So \(a_{n+1}\ge\sqrt2\) for every \(n\), and \(a_1=2>\sqrt2\) too. All terms are positive, so the argument applies at every step.

Nonincreasing. Since \(a_n\ge\sqrt2\) we have \(a_n^2\ge2\), so \(\frac2{a_n}\le a_n\) and

\[a_{n+1}-a_n=\frac12\left(\frac2{a_n}-a_n\right)\le0 .\]

Conclusion. By the Monotone Convergence Theorem, part (b), the sequence converges to some \(L\ge\sqrt2\). Taking limits in the recurrence gives \(L=\frac12\left(L+\frac2L\right)\), so \(2L=L+\frac2L\), \(L=\frac2L\), \(L^2=2\). Since \(L\ge\sqrt2>0\), \(L=\sqrt2\). (This is Newton’s method for \(\sqrt2\).)

Appendix B. Limit Facts for Sequences¶

Throughout, “for large \(n\)” means “for every \(n\) greater than some integer \(N\)”. We use the \(\varepsilon\)–\(N\) definition (Definition A.2) and the triangle inequality \(\abs{u+v}\le\abs u+\abs v\).

Theorem B.1: Uniqueness of limits

A sequence has at most one limit.

Proof. Suppose \(a_n\to L\) and \(a_n\to L'\) with \(L\ne L'\). Let \(\varepsilon=\frac12\abs{L-L'}>0\). There are integers \(N_1,N_2\) with \(\abs{a_n-L}<\varepsilon\) for \(n>N_1\) and \(\abs{a_n-L'}<\varepsilon\) for \(n>N_2\). For \(n>\max\{N_1,N_2\}\),

\[\abs{L-L'}\le\abs{L-a_n}+\abs{a_n-L'}<2\varepsilon=\abs{L-L'},\]

a contradiction. So \(L=L'\). ◻ ∎

Theorem B.2: Convergent sequences are bounded

If \(\{a_n\}\) converges, then there is a number \(K\) with \(\abs{a_n}\le K\) for every \(n\).

Proof. Let \(a_n\to L\). Taking \(\varepsilon=1\), there is \(N\) with \(\abs{a_n-L}<1\) for \(n>N\), so \(\abs{a_n}\le\abs L+1\) for \(n>N\). Take \(K=\max\{\abs{a_1},\dots,\abs{a_N},\abs L+1\}\). ◻ ∎

Theorem B.3: Tails and absolute values

(a) If \(a_n=b_n\) for all \(n>M\) (for some \(M\)), then \(\{a_n\}\) converges if and only if \(\{b_n\}\) converges, and then the limits are equal. Likewise \(a_n\to L\) if and only if \(a_{n+p}\to L\) for any fixed integer \(p\ge0\).

(b) \(a_n\to0\) if and only if \(\abs{a_n}\to0\).

Proof. (a) Let \(b_n\to L\) and \(\varepsilon>0\). There is \(N\) with \(\abs{b_n-L}<\varepsilon\) for \(n>N\). Then for \(n>\max\{N,M\}\) we have \(a_n=b_n\), so \(\abs{a_n-L}<\varepsilon\). The converse is the same with the roles exchanged. The shifted sequence \(a_{n+p}\) agrees, after the index change \(m=n+p\), with the terms \(a_m\), \(m>N+p\), so the same \(N\) works with \(N+p\) replaced by \(N\).

(b) The statements \(\abs{a_n-0}<\varepsilon\) and \(\abs{\,\abs{a_n}-0\,}<\varepsilon\) are the same inequality. ◻ ∎

Theorem B.4: Limit laws for sequences

Let \(a_n\to A\) and \(b_n\to B\), and let \(c\) be a constant. Then

(1) \(a_n\pm b_n\to A\pm B\);

(2) \(ca_n\to cA\);

(3) \(a_nb_n\to AB\);

(4) \(a_n/b_n\to A/B\), provided \(B\ne0\).

Proof. (1) Let \(\varepsilon>0\). Choose \(N_1,N_2\) with \(\abs{a_n-A}<\varepsilon/2\) for \(n>N_1\) and \(\abs{b_n-B}<\varepsilon/2\) for \(n>N_2\). For \(n>\max\{N_1,N_2\}\),

\[\abs{(a_n\pm b_n)-(A\pm B)}\le\abs{a_n-A}+\abs{b_n-B}<\varepsilon .\]

(2) If \(c=0\) the claim is trivial. Otherwise choose \(N\) with \(\abs{a_n-A}<\varepsilon/\abs c\) for \(n>N\); then \(\abs{ca_n-cA}=\abs c\,\abs{a_n-A}<\varepsilon\).

(3) By Theorem B.2 there is \(K>0\) with \(\abs{a_n}\le K\) for all \(n\). Write

\[a_nb_n-AB=a_n(b_n-B)+B(a_n-A),\]

so \(\abs{a_nb_n-AB}\le K\abs{b_n-B}+\abs B\,\abs{a_n-A}\). Choose \(N_1\) with \(\abs{b_n-B}<\frac{\varepsilon}{2K}\) for \(n>N_1\) and \(N_2\) with \(\abs{a_n-A}<\frac{\varepsilon}{2(\abs B+1)}\) for \(n>N_2\). For \(n>\max\{N_1,N_2\}\) the right side is less than \(\frac\varepsilon2+\frac\varepsilon2=\varepsilon\) (using \(\abs B<\abs B+1\)).

(4) First we show \(1/b_n\to1/B\). Since \(B\ne0\), take \(\varepsilon_0=\abs B/2\): there is \(N_0\) with \(\abs{b_n-B}<\abs B/2\) for \(n>N_0\), hence \(\abs{b_n}>\abs B/2\) (so \(b_n\ne0\)) for \(n>N_0\). For such \(n\),

\[\left|\frac1{b_n}-\frac1B\right|=\frac{\abs{B-b_n}}{\abs{b_n}\,\abs B}<\frac{2}{\abs B^{\,2}}\,\abs{b_n-B}.\]

Given \(\varepsilon>0\), choose \(N\ge N_0\) with \(\abs{b_n-B}<\frac{\varepsilon\abs B^{\,2}}2\) for \(n>N\); then the left side is less than \(\varepsilon\). Now \(a_n/b_n=a_n\cdot(1/b_n)\to A\cdot(1/B)\) by part (3). ◻ ∎

Theorem B.5: Squeeze Theorem for sequences

Suppose \(a_n\le b_n\le c_n\) for every \(n\) greater than some index \(M\). If \(a_n\to L\) and \(c_n\to L\), then \(b_n\to L\).

Proof. Let \(\varepsilon>0\). Choose \(N_1\) with \(\abs{a_n-L}<\varepsilon\) for \(n>N_1\), and \(N_2\) with \(\abs{c_n-L}<\varepsilon\) for \(n>N_2\). For \(n>\max\{M,N_1,N_2\}\),

\[L-\varepsilon<a_n\le b_n\le c_n<L+\varepsilon,\]

so \(\abs{b_n-L}<\varepsilon\). ◻ ∎

Theorem B.6: Limits of \(f(a_n)\) and of \(f(n)\)

(a) If \(a_n\to L\) and \(f\) is defined at every \(a_n\) and is continuous at \(L\), then \(f(a_n)\to f(L)\).

(b) If \(f(n)=a_n\) for every positive integer \(n\) and \(\lim_{x\to\infty}f(x)=L\), where \(L\) is a real number, \(\infty\) or \(-\infty\), then \(\lim_{n\to\infty}a_n=L\).

Proof. (a) Let \(\varepsilon>0\). By continuity of \(f\) at \(L\) there is \(\delta>0\) such that \(\abs{f(y)-f(L)}<\varepsilon\) whenever \(\abs{y-L}<\delta\). Since \(a_n\to L\) there is \(N\) with \(\abs{a_n-L}<\delta\) for \(n>N\). For those \(n\) we get \(\abs{f(a_n)-f(L)}<\varepsilon\).

(b) Suppose first that \(L\) is a real number and let \(\varepsilon>0\). Because \(f(x)\to L\) as \(x\to\infty\), there is a number \(X\) with \(\abs{f(x)-L}<\varepsilon\) for all \(x>X\). Let \(N\) be an integer with \(N\ge X\). For every \(n>N\) we have \(n>X\), so \(\abs{a_n-L}=\abs{f(n)-L}<\varepsilon\). If \(L=\infty\) and \(K\) is any number, there is \(X\) with \(f(x)>K\) for \(x>X\), and again \(N\ge X\) gives \(a_n=f(n)>K\) for \(n>N\). The case \(L=-\infty\) is the same. ◻ ∎

The converse of part (b) is false: if \(a_n=\cos(2\pi n)\) then \(a_n\to1\), but \(\lim_{x\to\infty}\cos(2\pi x)\) does not exist.

Example B.7: Finding \(N\) from \(\varepsilon\)

Prove that \(\displaystyle\lim_{n\to\infty}\frac{2n+1}{n+3}=2\), and find an \(N\) that works for \(\varepsilon=0.001\).

Plan. We must make \(\abs{a_n-2}\) small, so first simplify \(\abs{a_n-2}\) to something we can solve for \(n\).

Solution. For \(n\ge1\),

\[\left|\frac{2n+1}{n+3}-2\right|=\left|\frac{2n+1-2n-6}{n+3}\right|=\frac{5}{n+3}.\]

Now \(\frac5{n+3}<\varepsilon\) exactly when \(n+3>\frac5\varepsilon\), that is, when \(n>\frac5\varepsilon-3\). So given any \(\varepsilon>0\), any integer \(N\ge\frac5\varepsilon-3\) works: for every \(n>N\) we get \(n+3>\frac5\varepsilon\) and so \(\abs{a_n-2}<\varepsilon\). That proves the limit is \(2\).

For \(\varepsilon=0.001\): \(\frac5\varepsilon-3=4997\), so \(N=4997\) works. Check at the first index covered, \(n=4998\): \(\frac{5}{5001}<0.001\).

Example B.8: A Squeeze Theorem argument

Find \(\displaystyle\lim_{n\to\infty}\frac{n\sin n}{n^2+1}\).

Solution. The numerator oscillates, so the limit laws do not apply directly (they need \(\lim\sin n\) to exist, and it does not). Instead bound the terms. Since \(-1\le\sin n\le1\) and \(n^2+1>0\),

\[-\frac{n}{n^2+1}\le\frac{n\sin n}{n^2+1}\le\frac{n}{n^2+1}.\]

Both outer sequences tend to \(0\) because

\[\lim_{n\to\infty}\frac{n}{n^2+1}=\lim_{n\to\infty}\frac{1/n}{1+1/n^2}=\frac{0}{1+0}=0\]

by the limit laws (Theorem B.4). By the Squeeze Theorem (Theorem B.5), the limit is \(0\).

Example B.9: Proving that a sequence diverges

Prove directly from the definition that \(a_n=(-1)^n\) diverges.

Plan. If the sequence had a limit \(L\), then eventually all terms would be within a small distance of \(L\), including two consecutive terms. But consecutive terms are \(2\) apart, so they cannot both be close to one number.

Proof. Suppose \(a_n\to L\). Take \(\varepsilon=1\). There is \(N\) with \(\abs{a_n-L}<1\) for all \(n>N\). Pick any \(n>N\); then \(n\) and \(n+1\) are both greater than \(N\), and

\[2=\abs{a_n-a_{n+1}}=\abs{(a_n-L)+(L-a_{n+1})}\le\abs{a_n-L}+\abs{L-a_{n+1}}<1+1=2 .\]

This says \(2<2\), which is impossible. Hence no limit exists. (The same argument with \(\varepsilon\) smaller than half the gap shows that any sequence whose terms keep jumping between two different values diverges.)

Example B.10: A limit of the form \(f(a_n)\)

Find \(\displaystyle\lim_{n\to\infty}\cos\!\left(\frac{\pi n}{2n+1}\right)\).

Solution. Let \(a_n=\dfrac{n}{2n+1}\). Dividing numerator and denominator by \(n\), \(a_n=\dfrac{1}{2+1/n}\to\dfrac12\) by the limit laws. The function \(f(y)=\cos(\pi y)\) is continuous at every number, in particular at \(\frac12\). By Theorem B.6(a),

\[\cos(\pi a_n)\to\cos\!\left(\frac\pi2\right)=0 .\]
