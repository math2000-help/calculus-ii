Appendix: Sequences and Infinite Series¶

Download the PDF version

Guiding question

Chapter 10 leans on a few facts that its sections state and use but that need more care than a lecture allows: a bounded nondecreasing sequence converges, limits obey the usual laws, and a sequence squeezed between two sequences with the same limit has that limit. This appendix proves them. Section A starts from one assumption about the real numbers (completeness) and proves the Monotone Convergence Theorem from it. Section B uses the \(\varepsilon\)–\(N\) definition of a limit to prove the limit facts for sequences. Section C adds four facts needed by the sections on series: limits and inequalities, subsequences, and the limit at infinity of a monotone function (which settles when an improper integral of a positive function converges). Section E proves the limits of \(n\)-th roots (such as \(n^{1/n}\to1\)) that the Root Test needs. Nothing here is needed to use the facts, only to see why they are true.

Appendix A. Completeness and the Monotone Convergence Theorem¶

Definition A.1: Upper bound, supremum

Let \(S\) be a nonempty set of real numbers. A number \(M\) is an upper bound of \(S\) if \(s\le M\) for every \(s\) in \(S\); the set \(S\) is bounded above if it has an upper bound. A number \(M^*\) is the least upper bound (or supremum) of \(S\), written \(M^*=\sup S\), if

(i) \(M^*\) is an upper bound of \(S\), and

(ii) \(M^*\le M\) for every upper bound \(M\) of \(S\).

Lower bounds, bounded below and the greatest lower bound \(\inf S\) are defined in the same way with the inequalities reversed.

The supremum need not belong to the set. The set \(\{x : 0<x<1\}\) has supremum \(1\), which is not in the set, while the set \(\{x : 0<x\le 1\}\) has supremum \(1\), which is.

The Completeness Axiom

Every nonempty set of real numbers that is bounded above has a least upper bound.

This is an assumption about the real numbers, not a theorem: it cannot be derived from the rules of arithmetic and order, so we take it as the starting point. It is exactly what the rational numbers lack. The set of rational numbers \(q\) with \(q^2<2\) is bounded above by \(2\), but among the rational numbers it has no least upper bound. Every proof in this appendix, and the Monotone Convergence Theorem on which Chapter 10 relies, rests on it.

Definition A.2: Limit of a sequence

A sequence \(\{a_n\}\) converges to the number \(L\), written \(\lim_{n\to\infty}a_n=L\), if for every \(\varepsilon>0\) there is an integer \(N\) such that

\[\abs{a_n-L}<\varepsilon \quad\text{for every } n>N.\]

A sequence that does not converge diverges. We write \(a_n\to\infty\) if for every real number \(K\) there is an integer \(N\) such that \(a_n>K\) for every \(n>N\) (and \(a_n\to-\infty\) if \(a_n<K\) for every \(n>N\) in the same way); such a sequence diverges.

Theorem A.3: Approximation property of the supremum

Let \(S\) be nonempty and bounded above, and let \(M=\sup S\). For every \(\varepsilon>0\) there is an element \(s\) of \(S\) with \(M-\varepsilon<s\le M\).

Proof. Because \(M-\varepsilon<M\) and \(M\) is the least upper bound, the number \(M-\varepsilon\) is not an upper bound of \(S\). So some element \(s\) of \(S\) satisfies \(s>M-\varepsilon\). Also \(s\le M\), because \(M\) is an upper bound of \(S\). ◻ ∎

Theorem A.4: Archimedean property

For every real number \(x\) there is a positive integer \(n\) with \(n>x\). Consequently, for every \(\varepsilon>0\) there is a positive integer \(N\) with \(\dfrac1N<\varepsilon\).

Proof. Suppose, to the contrary, that some real number \(x\) satisfies \(n\le x\) for every positive integer \(n\). Then the set \(\N=\{1,2,3,\dots\}\) is nonempty and bounded above (by \(x\)), so by the Completeness Axiom it has a supremum \(M\). By Theorem A.3 with \(\varepsilon=1\) there is a positive integer \(n\) with \(n>M-1\). Then \(n+1\) is a positive integer and \(n+1>M\), which contradicts the fact that \(M\) is an upper bound of \(\N\). This proves the first statement.

For the second, apply the first statement to \(x=1/\varepsilon\): there is a positive integer \(N>1/\varepsilon\), and then \(1/N<\varepsilon\). ◻ ∎

Theorem A.5: Monotone Convergence Theorem

(a) If \(\{a_n\}\) is nondecreasing and bounded above, then \(\{a_n\}\) converges, and its limit is \(\sup\{a_n\}\).

(b) If \(\{a_n\}\) is nonincreasing and bounded below, then \(\{a_n\}\) converges, and its limit is \(\inf\{a_n\}\).

In particular, a bounded monotonic sequence converges.

Proof. (a) The set \(S=\{a_1,a_2,a_3,\dots\}\) is nonempty and bounded above, so \(L=\sup S\) exists by the Completeness Axiom. Let \(\varepsilon>0\). By Theorem A.3 there is an index \(N\) with \(L-\varepsilon<a_N\le L\). For every \(n>N\) we have \(a_n\ge a_N\) because the sequence is nondecreasing, and \(a_n\le L\) because \(L\) is an upper bound. Hence

\[L-\varepsilon<a_N\le a_n\le L, \qquad\text{so}\qquad \abs{a_n-L}<\varepsilon .\]

Since \(\varepsilon\) was arbitrary, \(a_n\to L\).

(b) The sequence \(b_n=-a_n\) is nondecreasing, and it is bounded above by \(-m\) if \(m\) is a lower bound of \(\{a_n\}\). By part (a), \(b_n\to L'\) with \(L'=\sup\{b_n\}\). Because \(\abs{a_n-(-L')}=\abs{b_n-L'}\), we get \(a_n\to-L'\). Finally \(-L'=\inf\{a_n\}\): every \(b_n\le L'\) gives \(a_n\ge-L'\), so \(-L'\) is a lower bound; and if \(m'\) is any lower bound of \(\{a_n\}\), then \(-m'\) is an upper bound of \(\{b_n\}\), so \(L'\le -m'\), that is \(m'\le -L'\). ◻ ∎

Theorem A.6: The limit of a monotone sequence respects bounds

If \(\{a_n\}\) is nondecreasing and \(a_n\le M\) for every \(n\), then \(\lim_{n\to\infty}a_n\le M\) (and \(\lim a_n\ge a_1\)). If \(\{a_n\}\) is nonincreasing and \(a_n\ge m\) for every \(n\), then \(\lim_{n\to\infty}a_n\ge m\).

Proof. In the nondecreasing case the limit is \(L=\sup\{a_n\}\) by Theorem A.5. Since \(M\) is an upper bound of \(\{a_n\}\) and \(L\) is the least upper bound, \(L\le M\); and \(L\ge a_1\) because \(L\) is an upper bound. The nonincreasing case is the same argument applied to \(-a_n\). ◻ ∎

Example A.7: A supremum that is not a maximum

Let \(S=\{1-\tfrac1n : n=1,2,3,\dots\}=\{0,\tfrac12,\tfrac23,\tfrac34,\dots\}\). Show that \(\sup S=1\) and that \(S\) has no largest element.

Solution. Step 1: \(1\) is an upper bound. Every element is \(1-\frac1n\) with \(\frac1n>0\), so every element is less than \(1\).

Step 2: nothing smaller is an upper bound. Let \(M<1\). We must find an element of \(S\) bigger than \(M\). The number \(1-M\) is positive, so by the Archimedean property (Theorem A.4) there is an integer \(N\) with \(\frac1N<1-M\). Rearranging, \(1-\frac1N>M\), so \(M\) is not an upper bound. Hence every upper bound is at least \(1\), and \(\sup S=1\).

Step 3: no maximum. A maximum would be an element equal to \(\sup S=1\), but every element is strictly less than \(1\).

As a check on the answer, the elements get closer and closer to \(1\): \(\lim_{n\to\infty}\left(1-\tfrac1n\right)=1\), so \(\sup S=1\).

Example A.8: Monotone Convergence in action: repeated square roots

Let \(a_1=\sqrt2\) and \(a_{n+1}=\sqrt{2+a_n}\). Show that \(\{a_n\}\) converges and find its limit.

Plan. The theorem needs two facts: the sequence is monotonic and it is bounded. Terms: \(a_1\approx1.414\), \(a_2\approx1.848\), \(a_3\approx1.962\). They increase; they seem to stay below \(2\).

Bounded above by \(2\) (induction). \(a_1=\sqrt2<2\). If \(a_n<2\), then \(a_{n+1}=\sqrt{2+a_n}<\sqrt{2+2}=2\), because the square root is increasing. So \(a_n<2\) for all \(n\).

Increasing (induction). \(a_2>a_1\) since \(\sqrt{2+\sqrt2}>\sqrt2\). If \(a_n>a_{n-1}\), then \(2+a_n>2+a_{n-1}\), and taking square roots, \(a_{n+1}>a_n\). So the sequence is increasing.

Conclusion. By the Monotone Convergence Theorem (Theorem A.5) the sequence converges, say to \(L\). Taking the limit in the recurrence (the limit of \(a_{n+1}\) is also \(L\), and the square root is continuous) gives \(L=\sqrt{2+L}\), so \(L^2-L-2=0\), that is \((L-2)(L+1)=0\). Because \(a_n>0\) for all \(n\), the limit is not \(-1\). Therefore \(L=2\), and by Theorem A.6 this agrees with \(L\le 2\).

Example A.9: A nonincreasing sequence bounded below

Let \(a_1=2\) and \(a_{n+1}=\dfrac12\left(a_n+\dfrac2{a_n}\right)\). Show that \(\{a_n\}\) converges and find its limit.

Terms. \(a_2=\frac12\left(2+1\right)=\frac32\) and \(a_3=\frac12\left(\frac32+\frac43\right)=\frac{17}{12}\).

Bounded below by \(\sqrt2\). For \(a_n>0\),

\[a_{n+1}^2-2=\frac14\left(a_n+\frac2{a_n}\right)^2-2=\frac14\left(a_n-\frac2{a_n}\right)^2\ge0 ,\]

because \(\left(u+v\right)^2-4uv=(u-v)^2\) with \(u=a_n\), \(v=2/a_n\) and \(uv=2\). So \(a_{n+1}\ge\sqrt2\) for every \(n\), and \(a_1=2>\sqrt2\) too. All terms are positive, so the argument applies at every step.

Nonincreasing. Since \(a_n\ge\sqrt2\) we have \(a_n^2\ge2\), so \(\frac2{a_n}\le a_n\) and

\[a_{n+1}-a_n=\frac12\left(\frac2{a_n}-a_n\right)\le0 .\]

Conclusion. By the Monotone Convergence Theorem, part (b), the sequence converges to some \(L\ge\sqrt2\). Taking limits in the recurrence gives \(L=\frac12\left(L+\frac2L\right)\), so \(2L=L+\frac2L\), \(L=\frac2L\), \(L^2=2\). Since \(L\ge\sqrt2>0\), \(L=\sqrt2\). (This is Newton’s method for \(\sqrt2\).)

Appendix B. Limit Facts for Sequences¶

Throughout, “for large \(n\)” means “for every \(n\) greater than some integer \(N\)”. We use the \(\varepsilon\)–\(N\) definition (Definition A.2) and the triangle inequality \(\abs{u+v}\le\abs u+\abs v\).

Theorem B.1: Uniqueness of limits

A sequence has at most one limit.

Proof. Suppose \(a_n\to L\) and \(a_n\to L'\) with \(L\ne L'\). Let \(\varepsilon=\frac12\abs{L-L'}>0\). There are integers \(N_1,N_2\) with \(\abs{a_n-L}<\varepsilon\) for \(n>N_1\) and \(\abs{a_n-L'}<\varepsilon\) for \(n>N_2\). For \(n>\max\{N_1,N_2\}\),

\[\abs{L-L'}\le\abs{L-a_n}+\abs{a_n-L'}<2\varepsilon=\abs{L-L'},\]

a contradiction. So \(L=L'\). ◻ ∎

Theorem B.2: Convergent sequences are bounded

If \(\{a_n\}\) converges, then there is a number \(K\) with \(\abs{a_n}\le K\) for every \(n\).

Proof. Let \(a_n\to L\). Taking \(\varepsilon=1\), there is \(N\) with \(\abs{a_n-L}<1\) for \(n>N\), so \(\abs{a_n}\le\abs L+1\) for \(n>N\). Take \(K=\max\{\abs{a_1},\dots,\abs{a_N},\abs L+1\}\). ◻ ∎

Theorem B.3: Tails and absolute values

(a) If \(a_n=b_n\) for all \(n>M\) (for some \(M\)), then \(\{a_n\}\) converges if and only if \(\{b_n\}\) converges, and then the limits are equal. Likewise \(a_n\to L\) if and only if \(a_{n+p}\to L\) for any fixed integer \(p\ge0\).

(b) \(a_n\to0\) if and only if \(\abs{a_n}\to0\).

Proof. (a) Let \(b_n\to L\) and \(\varepsilon>0\). There is \(N\) with \(\abs{b_n-L}<\varepsilon\) for \(n>N\). Then for \(n>\max\{N,M\}\) we have \(a_n=b_n\), so \(\abs{a_n-L}<\varepsilon\). The converse is the same with the roles exchanged. The shifted sequence \(a_{n+p}\) agrees, after the index change \(m=n+p\), with the terms \(a_m\), \(m>N+p\), so the same \(N\) works with \(N+p\) replaced by \(N\).

(b) The statements \(\abs{a_n-0}<\varepsilon\) and \(\abs{\,\abs{a_n}-0\,}<\varepsilon\) are the same inequality. ◻ ∎

Theorem B.4: Limit laws for sequences

Let \(a_n\to A\) and \(b_n\to B\), and let \(c\) be a constant. Then

(1) \(a_n\pm b_n\to A\pm B\);

(2) \(ca_n\to cA\);

(3) \(a_nb_n\to AB\);

(4) \(a_n/b_n\to A/B\), provided \(B\ne0\).

Proof. (1) Let \(\varepsilon>0\). Choose \(N_1,N_2\) with \(\abs{a_n-A}<\varepsilon/2\) for \(n>N_1\) and \(\abs{b_n-B}<\varepsilon/2\) for \(n>N_2\). For \(n>\max\{N_1,N_2\}\),

\[\abs{(a_n\pm b_n)-(A\pm B)}\le\abs{a_n-A}+\abs{b_n-B}<\varepsilon .\]

(2) If \(c=0\) the claim is trivial. Otherwise choose \(N\) with \(\abs{a_n-A}<\varepsilon/\abs c\) for \(n>N\); then \(\abs{ca_n-cA}=\abs c\,\abs{a_n-A}<\varepsilon\).

(3) By Theorem B.2 there is \(K>0\) with \(\abs{a_n}\le K\) for all \(n\). Write

\[a_nb_n-AB=a_n(b_n-B)+B(a_n-A),\]

so \(\abs{a_nb_n-AB}\le K\abs{b_n-B}+\abs B\,\abs{a_n-A}\). Choose \(N_1\) with \(\abs{b_n-B}<\frac{\varepsilon}{2K}\) for \(n>N_1\) and \(N_2\) with \(\abs{a_n-A}<\frac{\varepsilon}{2(\abs B+1)}\) for \(n>N_2\). For \(n>\max\{N_1,N_2\}\) the right side is less than \(\frac\varepsilon2+\frac\varepsilon2=\varepsilon\) (using \(\abs B<\abs B+1\)).

(4) First we show \(1/b_n\to1/B\). Since \(B\ne0\), take \(\varepsilon_0=\abs B/2\): there is \(N_0\) with \(\abs{b_n-B}<\abs B/2\) for \(n>N_0\), hence \(\abs{b_n}>\abs B/2\) (so \(b_n\ne0\)) for \(n>N_0\). For such \(n\),

\[\left|\frac1{b_n}-\frac1B\right|=\frac{\abs{B-b_n}}{\abs{b_n}\,\abs B}<\frac{2}{\abs B^{\,2}}\,\abs{b_n-B}.\]

Given \(\varepsilon>0\), choose \(N\ge N_0\) with \(\abs{b_n-B}<\frac{\varepsilon\abs B^{\,2}}2\) for \(n>N\); then the left side is less than \(\varepsilon\). Now \(a_n/b_n=a_n\cdot(1/b_n)\to A\cdot(1/B)\) by part (3). ◻ ∎

Theorem B.5: Squeeze Theorem for sequences

Suppose \(a_n\le b_n\le c_n\) for every \(n\) greater than some index \(M\). If \(a_n\to L\) and \(c_n\to L\), then \(b_n\to L\).

Proof. Let \(\varepsilon>0\). Choose \(N_1\) with \(\abs{a_n-L}<\varepsilon\) for \(n>N_1\), and \(N_2\) with \(\abs{c_n-L}<\varepsilon\) for \(n>N_2\). For \(n>\max\{M,N_1,N_2\}\),

\[L-\varepsilon<a_n\le b_n\le c_n<L+\varepsilon,\]

so \(\abs{b_n-L}<\varepsilon\). ◻ ∎

Theorem B.6: Limits of \(f(a_n)\) and of \(f(n)\)

(a) If \(a_n\to L\) and \(f\) is defined at every \(a_n\) and is continuous at \(L\), then \(f(a_n)\to f(L)\).

(b) If \(f(n)=a_n\) for every positive integer \(n\) and \(\lim_{x\to\infty}f(x)=L\), where \(L\) is a real number, \(\infty\) or \(-\infty\), then \(\lim_{n\to\infty}a_n=L\).

Proof. (a) Let \(\varepsilon>0\). By continuity of \(f\) at \(L\) there is \(\delta>0\) such that \(\abs{f(y)-f(L)}<\varepsilon\) whenever \(\abs{y-L}<\delta\). Since \(a_n\to L\) there is \(N\) with \(\abs{a_n-L}<\delta\) for \(n>N\). For those \(n\) we get \(\abs{f(a_n)-f(L)}<\varepsilon\).

(b) Suppose first that \(L\) is a real number and let \(\varepsilon>0\). Because \(f(x)\to L\) as \(x\to\infty\), there is a number \(X\) with \(\abs{f(x)-L}<\varepsilon\) for all \(x>X\). Let \(N\) be an integer with \(N\ge X\). For every \(n>N\) we have \(n>X\), so \(\abs{a_n-L}=\abs{f(n)-L}<\varepsilon\). If \(L=\infty\) and \(K\) is any number, there is \(X\) with \(f(x)>K\) for \(x>X\), and again \(N\ge X\) gives \(a_n=f(n)>K\) for \(n>N\). The case \(L=-\infty\) is the same. ◻ ∎

The converse of part (b) is false: if \(a_n=\cos(2\pi n)\) then \(a_n\to1\), but \(\lim_{x\to\infty}\cos(2\pi x)\) does not exist.

Example B.7: Finding \(N\) from \(\varepsilon\)

Prove that \(\displaystyle\lim_{n\to\infty}\frac{2n+1}{n+3}=2\), and find an \(N\) that works for \(\varepsilon=0.001\).

Plan. We must make \(\abs{a_n-2}\) small, so first simplify \(\abs{a_n-2}\) to something we can solve for \(n\).

Solution. For \(n\ge1\),

\[\left|\frac{2n+1}{n+3}-2\right|=\left|\frac{2n+1-2n-6}{n+3}\right|=\frac{5}{n+3}.\]

Now \(\frac5{n+3}<\varepsilon\) exactly when \(n+3>\frac5\varepsilon\), that is, when \(n>\frac5\varepsilon-3\). So given any \(\varepsilon>0\), any integer \(N\ge\frac5\varepsilon-3\) works: for every \(n>N\) we get \(n+3>\frac5\varepsilon\) and so \(\abs{a_n-2}<\varepsilon\). That proves the limit is \(2\).

For \(\varepsilon=0.001\): \(\frac5\varepsilon-3=4997\), so \(N=4997\) works. Check at the first index covered, \(n=4998\): \(\frac{5}{5001}<0.001\).

Example B.8: A Squeeze Theorem argument

Find \(\displaystyle\lim_{n\to\infty}\frac{n\sin n}{n^2+1}\).

Solution. The numerator oscillates, so the limit laws do not apply directly (they need \(\lim\sin n\) to exist, and it does not). Instead bound the terms. Since \(-1\le\sin n\le1\) and \(n^2+1>0\),

\[-\frac{n}{n^2+1}\le\frac{n\sin n}{n^2+1}\le\frac{n}{n^2+1}.\]

Both outer sequences tend to \(0\) because

\[\lim_{n\to\infty}\frac{n}{n^2+1}=\lim_{n\to\infty}\frac{1/n}{1+1/n^2}=\frac{0}{1+0}=0\]

by the limit laws (Theorem B.4). By the Squeeze Theorem (Theorem B.5), the limit is \(0\).

Example B.9: Proving that a sequence diverges

Prove directly from the definition that \(a_n=(-1)^n\) diverges.

Plan. If the sequence had a limit \(L\), then eventually all terms would be within a small distance of \(L\), including two consecutive terms. But consecutive terms are \(2\) apart, so they cannot both be close to one number.

Proof. Suppose \(a_n\to L\). Take \(\varepsilon=1\). There is \(N\) with \(\abs{a_n-L}<1\) for all \(n>N\). Pick any \(n>N\); then \(n\) and \(n+1\) are both greater than \(N\), and

\[2=\abs{a_n-a_{n+1}}=\abs{(a_n-L)+(L-a_{n+1})}\le\abs{a_n-L}+\abs{L-a_{n+1}}<1+1=2 .\]

This says \(2<2\), which is impossible. Hence no limit exists. (The same argument with \(\varepsilon\) smaller than half the gap shows that any sequence whose terms keep jumping between two different values diverges.)

Example B.10: A limit of the form \(f(a_n)\)

Find \(\displaystyle\lim_{n\to\infty}\cos\!\left(\frac{\pi n}{2n+1}\right)\).

Solution. Let \(a_n=\dfrac{n}{2n+1}\). Dividing numerator and denominator by \(n\), \(a_n=\dfrac{1}{2+1/n}\to\dfrac12\) by the limit laws. The function \(f(y)=\cos(\pi y)\) is continuous at every number, in particular at \(\frac12\). By Theorem B.6(a),

\[\cos(\pi a_n)\to\cos\!\left(\frac\pi2\right)=0 .\]

Appendix C. Limits, Inequalities and Monotone Functions¶

This section supports the study of series. It uses Definition A.2, the supremum facts of Section A and the limit facts of Section B.

Theorem C.1: Limits preserve non-strict inequalities

Suppose \(a_n\to A\), \(b_n\to B\), and \(a_n\le b_n\) for every \(n\) greater than some index \(M\). Then \(A\le B\). In particular, if \(a_n\ge m\) for large \(n\) and \(a_n\to A\), then \(A\ge m\).

Proof. Suppose, to the contrary, that \(A>B\), and let \(\varepsilon=\frac12(A-B)>0\). There is \(N\) with \(a_n>A-\varepsilon=\frac{A+B}2\) and \(b_n<B+\varepsilon=\frac{A+B}2\) for all \(n>N\). For \(n>\max\{M,N\}\) this gives \(b_n<\frac{A+B}2<a_n\), contradicting \(a_n\le b_n\). So \(A\le B\). For the second statement take the constant sequence \(b_n=m\), applied with the roles of the two sequences exchanged: \(m\le a_n\) gives \(m\le A\). ◻ ∎

Strict inequalities are not preserved: \(\frac1{n^2}<\frac1n\) for every \(n\ge2\), yet both sequences tend to \(0\).

Theorem C.2: Subsequences

Let \(S_n\to S\) and let \(n_1<n_2<n_3<\cdots\) be positive integers. Then \(S_{n_j}\to S\) as \(j\to\infty\). Consequently, if two subsequences of \(\{S_n\}\) have different limits, then \(\{S_n\}\) diverges.

Proof. First, \(n_j\ge j\) for every \(j\): \(n_1\ge1\), and if \(n_j\ge j\) then \(n_{j+1}>n_j\ge j\), so \(n_{j+1}\ge j+1\). Let \(\varepsilon>0\) and choose \(N\) with \(\abs{S_n-S}<\varepsilon\) for \(n>N\). For \(j>N\) we have \(n_j\ge j>N\), so \(\abs{S_{n_j}-S}<\varepsilon\). The second statement is the contrapositive combined with uniqueness of limits (Theorem B.1): if \(S_n\to S\), every subsequence tends to the same \(S\). ◻ ∎

We use the definition of the limit of a function at infinity from Calculus I: \(\lim_{x\to\infty}g(x)=L\) means that for every \(\varepsilon>0\) there is a number \(X\) such that \(\abs{g(x)-L}<\varepsilon\) for all \(x>X\); and \(\lim_{x\to\infty}g(x)=\infty\) means that for every \(K\) there is \(X\) with \(g(x)>K\) for all \(x>X\).

Theorem C.3: A monotone function has a limit at infinity

Let \(g\) be defined on \([a,\infty)\) and nondecreasing, that is, \(g(x)\le g(y)\) whenever \(a\le x<y\).

(a) If \(g\) is bounded above, then \(\lim_{x\to\infty}g(x)\) exists and equals \(\sup\{g(x):x\ge a\}\).

(b) If \(g\) is not bounded above, then \(g(x)\to\infty\) as \(x\to\infty\).

Proof. (a) The set \(\{g(x):x\ge a\}\) is nonempty and bounded above, so \(M=\sup\{g(x):x\ge a\}\) exists by the Completeness Axiom. Let \(\varepsilon>0\). By Theorem A.3 there is \(x_0\ge a\) with \(M-\varepsilon<g(x_0)\le M\). For every \(x>x_0\), monotonicity gives \(M-\varepsilon<g(x_0)\le g(x)\le M\), so \(\abs{g(x)-M}<\varepsilon\). Hence \(g(x)\to M\).

(b) Let \(K\) be a number. Since \(K\) is not an upper bound of \(g\), there is \(x_0\) with \(g(x_0)>K\), and then \(g(x)\ge g(x_0)>K\) for all \(x>x_0\). ◻ ∎

Theorem C.4: Improper integrals of nonnegative functions

Let \(f\) be continuous on \([a,\infty)\) with \(f(x)\ge0\), and let \(F(b)=\int_a^bf(x)\,dx\) for \(b\ge a\). Then \(F\) is nondecreasing, and:

(a) the improper integral \(\int_a^\infty f(x)\,dx=\lim_{b\to\infty}F(b)\) converges if and only if \(F\) is bounded above, and then \(F(b)\le\int_a^\infty f(x)\,dx\) for every \(b\);

(b) \(F\) is bounded above if and only if the numbers \(F(n)\), for integers \(n\ge a\), are bounded above;

(c) if \(F\) is not bounded above, then \(\int_a^\infty f(x)\,dx=\infty\) (the integral diverges).

Proof. If \(a\le b<c\) then \(F(c)-F(b)=\int_b^cf(x)\,dx\ge0\) because \(f\ge0\), so \(F\) is nondecreasing. Parts (a) and (c) follow from Theorem C.3. If \(F\) is bounded above, the limit exists and equals \(\sup F\), which is at least every \(F(b)\). If \(F\) is not bounded above, then \(F(b)\to\infty\), so the improper integral does not converge; this proves (c) and shows that a convergent integral forces \(F\) to be bounded above. For (b), one direction is trivial. Conversely, suppose \(F(n)\le K\) for all integers \(n\ge a\). Given any \(b\ge a\), choose an integer \(n\ge b\); then \(F(b)\le F(n)\le K\). ◻ ∎

Example C.5: Bounded or unbounded integrals

Decide whether \(\int_1^\infty e^{-x}\,dx\) and \(\int_1^\infty\frac1x\,dx\) converge, using Theorem C.4.

Solution. Both integrands are positive and continuous on \([1,\infty)\). For \(F(b)=\int_1^be^{-x}\,dx=e^{-1}-e^{-b}\) we have \(F(b)<e^{-1}\) for every \(b\), so \(F\) is bounded above and the integral converges, to \(e^{-1}\approx0.368\). For \(G(b)=\int_1^b\frac1x\,dx=\ln b\), the values \(G(e^m)=m\) for \(m=1,2,3,\dots\) are not bounded above, so by part (b) \(G\) is not bounded above and the integral diverges. Notice that the integrand \(\frac1x\) tends to \(0\) and still the integral is infinite: “small integrand” does not mean “finite integral”, exactly as “small terms” does not mean “finite sum”.

Example C.6: Subsequences settle a question about divergence

Show that the sequence \(S_n=\frac{1+(-1)^n}2\) (that is, \(0,1,0,1,\dots\)) diverges, and that \(S_n=\frac{1-(-1)^n}2\) has the same property.

Solution. The even-numbered terms are \(S_{2j}=\frac{1+1}2=1\) for every \(j\), a constant sequence with limit \(1\). The odd-numbered terms are \(S_{2j-1}=\frac{1-1}2=0\), a constant sequence with limit \(0\). These are two subsequences with different limits, so by Theorem C.2 the sequence diverges. The second sequence is the first one shifted by one place, with the roles of \(0\) and \(1\) swapped, and the same argument applies.

Appendix D. Splitting Sequences, Sign Parts and Rearranging Series¶

This section supports the sections on alternating series and on absolute and conditional convergence. The first two results are proved in full. Rearranging series is different: the two main theorems are stated and sketched, but their full proofs are omitted here (they need more room than a reference appendix has). One rearrangement is worked out completely, because it shows why the theorems are needed.

Theorem D.1: Splitting a sequence into residue classes

Let \(q\ge2\) be an integer and \(\{S_n\}\) a sequence. If, for each \(r=0,1,\dots,q-1\), the subsequence \(S_{qj+r}\) (the terms whose index leaves remainder \(r\) on division by \(q\)) tends to the same number \(L\) as \(j\to\infty\), then \(S_n\to L\). In particular (take \(q=2\)): if \(S_{2j}\to L\) and \(S_{2j-1}\to L\), then \(S_n\to L\).

Proof. Let \(\varepsilon>0\). For each \(r\) there is a number \(J_r\) with \(\abs{S_{qj+r}-L}<\varepsilon\) for all \(j>J_r\). Put \(J=\max\{J_0,\dots,J_{q-1}\}\) and \(N=q(J+1)\). Let \(n>N\) and write \(n=qj+r\) with \(0\le r<q\). Then \(qj+r>q(J+1)\) gives \(j>J+1-\frac rq>J\) (because \(r<q\)), so \(j>J\ge J_r\) and \(\abs{S_n-L}<\varepsilon\). Hence \(S_n\to L\). For \(q=2\) the odd terms are \(S_{2j-1}=S_{2(j-1)+1}\), a shift of the class \(r=1\), and a shifted sequence has the same limit (Theorem B.3). ◻ ∎

Example D.2: Even terms and odd terms

The sequence \(S_n=\dfrac{n+(-1)^n}{n}\) has \(S_{2j}=1+\dfrac1{2j}\to1\) and \(S_{2j-1}=1-\dfrac1{2j-1}\to1\). Conclude that \(S_n\to1\), and explain why one class alone would not be enough.

Solution. Both classes tend to \(1\), so \(S_n\to1\) by Theorem D.1 (here also \(S_n=1+\frac{(-1)^n}n\) and the Squeeze Theorem gives the same result). One class alone is not enough: for \(T_n=1+(-1)^n\), the even terms are all \(2\), so \(T_{2j}\to2\), but the odd terms are all \(0\), so \(T_n\) has no limit. Theorem D.1 needs every class to have the same limit.

For a series \(\sum a_k\) write \(a_k^+=\max\{a_k,0\}\) (the positive part) and \(a_k^-=\max\{-a_k,0\}\) (the negative part). Both are \(\ge0\), and

\[a_k=a_k^+-a_k^-,\qquad \abs{a_k}=a_k^++a_k^- ,\qquad a_k^+=\frac{\abs{a_k}+a_k}2,\qquad a_k^-=\frac{\abs{a_k}-a_k}2 .\]

Theorem D.3: Positive and negative parts

(a) If \(\sum\abs{a_k}\) converges, then \(\sum a_k^+\) and \(\sum a_k^-\) both converge.

(b) If \(\sum a_k\) converges but \(\sum\abs{a_k}\) diverges, then \(\sum a_k^+\) and \(\sum a_k^-\) both diverge: their partial sums are not bounded above.

Proof. Let \(P_n=\sum_{k=1}^na_k^+\), \(M_n=\sum_{k=1}^na_k^-\), \(A_n=\sum_{k=1}^n\abs{a_k}=P_n+M_n\) and \(S_n=\sum_{k=1}^na_k=P_n-M_n\).

(a) The sequences \(\{P_n\}\) and \(\{M_n\}\) are nondecreasing (their terms are \(\ge0\)) and \(P_n\le A_n\le A\), \(M_n\le A_n\le A\), where \(A=\sum\abs{a_k}\) is the limit of the nondecreasing sequence \(\{A_n\}\) (Theorem A.6). By the Monotone Convergence Theorem both converge.

(b) Suppose \(\{P_n\}\) converged, to \(P\). Then \(M_n=P_n-S_n\to P-S\), so \(A_n=P_n+M_n\) would converge, contradicting the divergence of \(\sum\abs{a_k}\). The same argument with the roles of \(P_n\) and \(M_n\) exchanged (use \(P_n=M_n+S_n\)) shows that \(\{M_n\}\) does not converge either. A nondecreasing sequence that does not converge is not bounded above, by the Monotone Convergence Theorem. ◻ ∎

Example D.4: The parts of the alternating harmonic series

For \(a_k=\dfrac{(-1)^{k+1}}k\) find \(a_k^+\) and \(a_k^-\) and describe their partial sums.

Solution. \(a_k^+=\frac1k\) for odd \(k\) and \(0\) for even \(k\); \(a_k^-=\frac1k\) for even \(k\) and \(0\) for odd \(k\). So \(\sum a_k^+=1+\frac13+\frac15+\cdots\) and \(\sum a_k^-=\frac12+\frac14+\frac16+\cdots\). Since the alternating harmonic series converges but \(\sum\frac1k\) diverges, Theorem D.3(b) says both of these diverge. This can also be seen directly: \(\sum_{j=1}^m\frac1{2j-1}>\sum_{j=1}^m\frac1{2j}=\frac12H_m\to\infty\).

Rearranging a series¶

A rearrangement of \(\sum a_k\) is a series \(\sum a_{\sigma(k)}\) that has the same terms in a different order (\(\sigma\) is a one-to-one correspondence of the positive integers with themselves). For finite sums the order never matters. For infinite sums it can.

Example D.5: Reordering the alternating harmonic series halves its sum

Let \(S=1-\frac12+\frac13-\frac14+\cdots\) be the alternating harmonic series (it converges, by the Alternating Series Test treated in the section on alternating series; its value is \(\ln2\approx0.693\), as the chapter on power series will show). Take its terms in this order: one positive term, then two negative terms,

\[R=1-\frac12-\frac14+\frac13-\frac16-\frac18+\frac15-\frac1{10}-\frac1{12}+\cdots,\]

so group \(j\) is \(\dfrac1{2j-1}-\dfrac1{4j-2}-\dfrac1{4j}\). Every term of \(S\) appears exactly once in \(R\): the positive terms \(\frac1{2j-1}\) in order; the negative terms \(-\frac1{4j-2}=-\frac1{2(2j-1)}\) and \(-\frac1{4j}\) are the terms \(-\frac1m\) with \(m\equiv2\) and \(m\equiv0\pmod4\), that is all the even \(m\). Show that \(R=\frac12S\). In particular \(R\ne S\).

Solution. Let \(R_n\) be the partial sums of \(R\) and \(S_n\) those of \(S\). Since \(\frac1{4j-2}=\frac12\cdot\frac1{2j-1}\), group \(j\) equals

\[\frac1{2j-1}-\frac1{2(2j-1)}-\frac1{4j}=\frac12\cdot\frac1{2j-1}-\frac12\cdot\frac1{2j}=\frac12\left(\frac1{2j-1}-\frac1{2j}\right).\]

Adding \(j=1,\dots,m\) gives \(R_{3m}=\frac12S_{2m}\). Because \(S_{2m}\to S\), \(R_{3m}\to\frac12S\). The other two classes differ from \(R_{3m}\) by the next terms: \(R_{3m+1}=R_{3m}+\frac1{2m+1}\) and \(R_{3m+2}=R_{3m}+\frac1{2m+1}-\frac1{4m+2}\), and both added amounts tend to \(0\). So all three subsequences \(R_{3m}\), \(R_{3m+1}\), \(R_{3m+2}\) tend to \(\frac12S\), and \(R_n\to\frac12S\) by Theorem D.1. Finally \(S>0\): the partial sums \(S_{2m}\) are nondecreasing (each step adds \(\frac1{2m-1}-\frac1{2m}>0\)), so \(S\ge S_2=\frac12\) by Theorem A.6, and \(R=\frac12S\ne S\). The same terms, in a different order, have a different sum.

Two theorems describe exactly what can happen. The proofs below are omitted; only a sketch is given.

Theorem D.6: Rearranging an absolutely convergent series

If \(\sum\abs{a_k}\) converges, then every rearrangement of \(\sum a_k\) converges, and to the same sum as \(\sum a_k\).

Proof omitted. Sketch. Let \(S\) be the sum and \(\varepsilon>0\). Choose \(N\) with \(\sum_{k>N}\abs{a_k}<\varepsilon\). In the rearranged series, wait until the terms \(a_1,\dots,a_N\) have all appeared, say by position \(M\). For \(n\ge M\) the partial sum of the rearrangement is \(a_1+\cdots+a_N\) plus some terms \(a_k\) with \(k>N\), while the true partial sum \(S_N\) is \(a_1+\cdots+a_N\) alone. So the rearranged partial sum differs from \(S_N\) by at most \(\sum_{k>N}\abs{a_k}<\varepsilon\), and \(S_N\) differs from \(S\) by at most the same amount. The step that needs care is that \(\abs{\sum_{k>N}a_k}\le\sum_{k>N}\abs{a_k}\) for the infinite tail.

Theorem D.7: Rearranging a conditionally convergent series (Riemann)

If \(\sum a_k\) converges but \(\sum\abs{a_k}\) diverges, then for every real number \(A\) there is a rearrangement of \(\sum a_k\) whose sum is \(A\). There are also rearrangements whose partial sums tend to \(\infty\), and rearrangements that have no limit.

Proof omitted. Sketch. By Theorem D.3(b) the positive terms add to \(+\infty\) and the negative terms to \(-\infty\), while \(a_k\to0\). To aim at \(A\): add positive terms, in their original order, until the running total first exceeds \(A\); then add negative terms until it first drops below \(A\); then positive terms again; and so on. This uses every term exactly once, because each stage needs only finitely many terms (the supply of each sign is unlimited). After the first crossing of \(A\), the running total never misses \(A\) by more than the size of the last term used, and the terms tend to \(0\), so the running totals tend to \(A\). The details of “never misses by more than” and of showing that every term is used are what the full proof supplies.

Example D.8: Aiming at \(\frac32\)

Follow the sketch for the alternating harmonic series with the target \(A=\frac32\), and list the first stages.

Solution. The positive terms are \(1,\frac13,\frac15,\dots\) and the negative terms are \(-\frac12,-\frac14,\dots\) Add positive terms until the total exceeds \(\frac32\): \(1+\frac13=\frac43<\frac32\), and \(\frac43+\frac15=\frac{23}{15}\approx1.533>\frac32\). Now add negative terms until the total drops below \(\frac32\): already the first one does, \(\frac{23}{15}-\frac12=\frac{31}{30}\approx1.033<\frac32\). Add positive terms again: \(\frac{31}{30}+\frac17+\frac19+\frac1{11}+\frac1{13}\approx1.4551<\frac32\), and one more, \(\frac1{15}\), gives \(\approx1.5218>\frac32\). The series begins \(1+\frac13+\frac15-\frac12+\frac17+\frac19+\frac1{11}+\frac1{13}+\frac1{15}-\frac14+\cdots\), and its totals swing around \(\frac32\) by smaller and smaller amounts (a computer run of \(10^5\) terms ends within \(10^{-4}\) of \(\frac32\)).

Appendix E. Limits of \(n\)-th Roots¶

The Root Test asks for the limit of \(\abs{a_k}^{1/k}\), and for the common terms of series (powers of \(k\) times a constant, or a rational function of \(k\)) that limit is \(\lim n^{1/n}\) or one very close to it. This section proves the limits that are needed, using only the Squeeze Theorem (Theorem B.5), the limit laws (Theorem B.4), limits of \(f(a_n)\) (Theorem B.6) and the binomial theorem. One further limit is used in the section on the Ratio and Root Tests and is not proved here: \(\left(1+\frac1n\right)^n\to e\), which is how the number \(e\) is defined in Calculus I.

Theorem E.1: The limit of \(n^{1/n}\)

\(\displaystyle\lim_{n\to\infty}n^{1/n}=1\).

Proof. Let \(n\ge2\) and write \(n^{1/n}=1+h_n\). Since \(n\ge1\), we have \(n^{1/n}\ge1\), so \(h_n\ge0\). By the binomial theorem, all of whose terms are nonnegative here,

\[n=(1+h_n)^n=1+nh_n+\binom n2h_n^2+\cdots\ \ge\ \binom n2h_n^2=\frac{n(n-1)}2\,h_n^2 .\]

Dividing by \(\frac{n(n-1)}2>0\) gives \(h_n^2\le\frac2{n-1}\), so \(0\le h_n\le\sqrt{2/(n-1)}\), that is,

\[1\le n^{1/n}\le1+\sqrt{\frac2{n-1}} .\]

The right side tends to \(1\) (limit laws, and Theorem B.6(a) for the square root, which is continuous at \(0\)). By the Squeeze Theorem, \(n^{1/n}\to1\). ◻ ∎

Theorem E.2: Roots of constants

If \(c>0\), then \(\displaystyle\lim_{n\to\infty}c^{1/n}=1\).

Proof. Suppose first that \(c\ge1\). For every \(n\ge c\) we have \(1\le c\le n\), and \(t\mapsto t^{1/n}\) is increasing, so \(1\le c^{1/n}\le n^{1/n}\). Both outer sequences tend to \(1\) (Theorem E.1), so \(c^{1/n}\to1\) by the Squeeze Theorem. Now suppose \(0<c<1\). Then \(\frac1c>1\), so \(\left(\frac1c\right)^{1/n}\to1\) by the first case, and

\[c^{1/n}=\frac1{(1/c)^{1/n}}\to\frac11=1\]

by the limit laws. ◻ ∎

Theorem E.3: Roots of powers times a positive limit

Let \(p\) be a real number and let \(c_n>0\) with \(c_n\to L\), where \(L>0\). Then \(\displaystyle\lim_{n\to\infty}\left(n^pc_n\right)^{1/n}=1\).

Proof. The factor \(c_n\). Take \(\varepsilon=\frac L2\) in the definition of the limit: there is \(N\) with \(\frac L2<c_n<\frac{3L}2\) for \(n>N\). Raising to the power \(\frac1n\) (an increasing operation), \(\left(\frac L2\right)^{1/n}<c_n^{1/n}<\left(\frac{3L}2\right)^{1/n}\). Both outer sequences tend to \(1\) (Theorem E.2), so \(c_n^{1/n}\to1\) by the Squeeze Theorem.

The factor \(n^p\). \((n^p)^{1/n}=\left(n^{1/n}\right)^p\to1^p=1\), by Theorem E.1 and Theorem B.6(a) applied to \(y\mapsto y^p\), which is continuous at \(1\).

Product. For positive numbers \((xy)^{1/n}=x^{1/n}y^{1/n}\), so \(\left(n^pc_n\right)^{1/n}=\left(n^{1/n}\right)^p\,c_n^{1/n}\to1\cdot1=1\) by the product law. ◻ ∎

Example E.4: How slowly \(n^{1/n}\) approaches \(1\)

Compute \(n^{1/n}\) for \(n=2,3,10,100,1000\) and compare with the bound in the proof.

Solution. \(2^{1/2}\approx1.4142\), \(3^{1/3}\approx1.4423\), \(10^{1/10}\approx1.2589\), \(100^{1/100}\approx1.0471\), \(1000^{1/1000}\approx1.0069\). The sequence first rises (to its largest value at \(n=3\), because \(\frac{\ln x}x\) has its maximum at \(x=e\)) and only then falls to \(1\), and it falls slowly. The bound \(1+\sqrt{2/(n-1)}\) is valid but crude: at \(n=1000\) it is \(\approx1.0447\), while the true value is \(1.0069\). So the limit is a statement about very large \(n\).

Example E.5: Roots of rational expressions

Find (a) \(\displaystyle\lim_{n\to\infty}\left(\frac{3n^2+1}{n^2+5}\right)^{1/n}\), (b) \(\displaystyle\lim_{n\to\infty}\left(7n^{10}\right)^{1/n}\), (c) \(\displaystyle\lim_{n\to\infty}\left(\frac{5n+1}{n^4}\right)^{1/n}\).

Solution. (a) The fraction tends to \(3>0\), so with \(p=0\) Theorem E.3 gives \(1\). (b) Take \(p=10\) and \(c_n=7\): the limit is \(1\). (c) Write \(\frac{5n+1}{n^4}=n^{-3}\left(5+\frac1n\right)\): here \(p=-3\) and \(c_n=5+\frac1n\to5>0\), so the limit is \(1\). In every case the root of a quantity that is only polynomial in \(n\) is \(1\) in the limit, and only a genuinely exponential factor (\(2^n\), \(\left(1+\frac1n\right)^{n^2}\), …) changes the answer.
